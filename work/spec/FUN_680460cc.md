# FUN_680460cc (FastSim_FROSTER) params=32

DRAFT (GLM-Flash, unaudited)

## 1) PURPOSE
Decides whether to replace the baserunner on a given base with a pinch runner, by summing situation/speed/injury adjustments into a percentage chance and rolling against it.

## 2) INPUTS
- `param_1` — base selector: 2 = 1st, 3 = 2nd, 4 = 3rd (inferred from PB usage and base table indexing).
- `this` (team/game object):
  - `this + i*4`, i = 0..39 — int list of player IDs.
  - `this + i*0x93c + 0x144` — player name (used only in log).
  - `this + i*0x93c + 0x3de` — status record; `FUN_6803dded(rec)==0` = eligible (guess: not currently in game); `FUN_6803dec5(rec,4)!=0` = injured flag (guess).
  - `this + i*0x93c + 0x7f0` — speed rating, int via `FUN_6803e2e1(rec,0)` (guess: 0–99).
  - `this + 0x1733e` — object passed to bench-count helper (guess: bench/dugout).
- Globals: `DAT_681147db` — short array, runner ID per base (index = `param_1`; elements at +0xdf/+0xe1/+0xe3 are the 1st/2nd/3rd occupancy values); `DAT_68143ee0` — game state (inning via `FUN_6800f200`, outs via `FUN_68002c80`, scores via `FUN_68056985(state, 3|4, 0)`); `DAT_68114ba4` — log-enable flag; `DAT_68185a60` — RNG state.

## 3) RULES
1. Runner ID = `DAT_681147db[param_1]`; if 0 (base empty), return without substituting.
2. Locate the runner's index by linear scan of the 40-entry ID list; if absent, call error reporter `FUN_68082319("...FastSim_FROSTER.cpp", 0x11fb, ...)` and continue (see §5).
3. Read runner speed `S`, inning `I`, outs `O`, score diff `SD = score(3) − score(4)`, occupancy flags `B1/B2/B3` (from `DAT_681147df/e1/e3 != 0`).
4. Base chance: 1st → `PB[prChanceOnFirstBase]`; 2nd → `PB[prChanceOnSecondBase]`; 3rd → `PB[prChanceOnThirdBase]`.
5. `R` = occupied bases from this base inclusive: 1st → `B1+B2+B3`; 2nd → `B2+B3`; 3rd → `B3`.
6. Situation: if `−SD == R−1` → `+= PB[prChanceWinningRun]`; else if `−SD == R` → `+= PB[prChanceTyingRun]`; else → `+= PB[prChanceInsignificant]`. (Code treats `−SD` as the batting team's deficit — inferred.)
7. `+= PB[prChancePerOutAdjust] * O`.
8. Inning: `I<4` → `+= PB[prChanceEarlyInnAdjust]`; `I<7` → `PB[prChanceMidInnAdjust]`; `I<9` → `PB[prChanceLateInnAdjust]`; `I<10` → `PB[prChanceInn9Adjust]`; else `PB[prChanceExtraInnAdjust]`.
9. `+= FUN_6800f0e0(this+0x1733e, 0, 5) * PB[prChancePerBenchPlayerAdjust]` (bench player count — guess).
10. Runner speed ladder (tests are `<`, so category = highest threshold met): `S >= PB[prChanceVeryFastSPThresh]` → `+= PB[prChanceVeryFastSPAdjust]`; `>= PB[prChanceFastSPThresh]` → `PB[prChanceFastSPAdjust]`; `>= PB[prChanceMedSPThresh]` → `PB[prChanceMedSPAdjust]`; `>= PB[prChanceSlowSPThresh]` → `PB[prChanceSlowSPAdjust]`; else `PB[prChanceVerySlowSPAdjust]`.
11. Scan all 40 players; eligible = `FUN_6803dded(status)==0`; select the one with the highest speed (first wins ties). If none, return without substituting.
12. Bench speed ladder, same structure on the candidate's speed: `>= PB[prChanceVeryFastPRThresh]` → `+= PB[prChanceVeryFastPRAdjust]`; `>= PB[prChanceFastPRThresh]` → `PB[prChanceFastPRAdjust]`; `>= PB[prChanceMedPRThresh]` → `PB[prChanceMedPRAdjust]`; `>= PB[prChanceSlowPRThresh]` → `PB[prChanceSlowPRAdjust]`; else `PB[prChanceVerySlowPRAdjust]`.
13. If `FUN_6803dec5(runner status, 4) != 0`: `+= FUN_6804916c(this, runnerID) * PB[prChancePerInjuryPointAdjust]` (injury points — guess).
14. Roll `r = FUN_68082999(&DAT_68185a60, 100)`; if `r < chance` → call `FUN_68041d33(this, bestCandidateIndex)` to perform the substitution. Chance is never clamped; with defaults a negative total can never trigger.

## 4) OUTPUT / SIDE EFFECTS
- Possibly executes the pinch-runner swap (`FUN_68041d33`); no value returned to caller.
- If `DAT_68114ba4` set and chance > 0: emits debug log — "=== Check_For_Sub ===", "Pinch Run: %s in for %s" (candidate name, runner name via +0x144), "Chance: %d". Logged before the roll, so it prints even when the roll fails.
- Error log if the runner ID is not found in the 40-player list.
