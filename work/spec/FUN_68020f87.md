# FUN_68020f87 (void __fastcall FUN_68020f87(int param_1))

DRAFT (GLM-Flash, unaudited)

## PURPOSE
For each of four objects fetched from a global list, greedily advances a per-object state index (0–3) step by step, accumulating a per-step cost, and records the furthest index whose cumulative cost minus a per-index table offset stays below PB[likelyOutFrames].

## INPUTS
- `param_1` (arg): pointer to caller's record; used only as write target — dword slots at byte offsets 6, 10, 14, 18 (one per entity n = 1..4).
- Global object list at `DAT_68143e28`, indexed 1..4 via `FUN_6801f5f0` (guess: four game entities — bases/fielders/etc., not determinable).
- Global short table at `DAT_680d26b0`, 4 entries read via `FUN_68023268` → `T[0..3]`; only T[1..3] are ever used (guess: per-index frame allowance/offset).
- `PB[likelyOutFrames]` (default 20): cost budget; re-read on every inner-loop step.
- Per object: validity char from `FUN_68021a40(obj)`; "current index" from the call Ghidra labels `CSplitterWnd::IsTracking(obj)` (almost certainly a mislabeled virtual/getter — see UNCERTAIN); sub-object at `obj+8` passed to both cost functions; per-index handles from `FUN_6800a3a6(i)`, i = 0..3.

## RULES
1. Once at entry: `T[i] = FUN_68023268(&DAT_680d26b0, i)` for i = 0..3.
2. For n = 1..4 (function returns as soon as n would exceed 4):
   - 2.1 `obj = FUN_6801f5f0(&DAT_68143e28, n)`; if `FUN_68021a40(obj) == 0`, skip entity n — its output slot is not written.
   - 2.2 `idx = F(obj)` (the IsTracking-labeled call); store `out[n] = idx` at `param_1 + 2 + n*4` immediately, before any stepping.
   - 2.3 `acc = 0`; while `idx < 3`:
     - `next = idx + 1`; `hNext = FUN_6800a3a6(next)`.
     - If `F(obj) == idx`: `step = FUN_68003988(obj+8, hNext)` (short).
       Else: `step = FUN_6800395c(obj+8, hNext, FUN_6800a3a6(idx))` (short).
     - `acc = acc + step`.
     - If `PB[likelyOutFrames] <= acc - T[next]`: break — `out[n]` keeps its current value.
     - Otherwise `out[n] = next; idx = next;` and loop.
3. Net effect: `out[n]` is the largest index i reachable from the initial `F(obj)` such that (sum of step costs through reaching i) − T[i] < PB[likelyOutFrames]. Index 3 is the ceiling; the initial index is always recorded if the validity check passes, even if no step is taken.

## OUTPUT / SIDE EFFECTS
- Writes four dwords (values 0..3) at `param_1+6`, `+10`, `+14`, `+18`. Slots of entities failing the validity check are left untouched (stale caller value persists).
- No other writes visible in this function; helper functions (`FUN_6800a3a6`, `FUN_68023268`, `FUN_68003988`, `FUN_6800395c`, F) may have side effects not visible here.
