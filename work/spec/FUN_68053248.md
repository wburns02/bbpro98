# FUN_68053248 (uint __fastcall FUN_68053248(int param_1))

DRAFT (GLM-Flash, unaudited)

## 1) PURPOSE
Computes a 0–100 probability that the AI calls a "hnr" play (per PB naming; hit-and-run inferred from the runner-on-base / pitcher-hold logic) for the current situation, or 0 if preconditions fail.

## 2) INPUTS
- `param_1` — game/view object.
  - `+0x6b`: object pointer used for three calls Ghidra labels `CSplitterWnd::IsTracking`; first result gates (must be 0), other two supply the "CH" and "PH" rating bytes (labels suspect — likely rating getters, guess).
  - `+0x7b`: int selecting one of two team data blocks (`0x68114ba8` or `+0x173be`) for the wildness check (home/away, guess).
- `FUN_68032ff0(param_1)` — returns a handle/flag; nonzero required; handle passed to `FUN_68038e10` to get the "SP" byte (guess: current batter or runner-on-1st record).
- `FUN_6800f600(param_1)`, `FUN_6800f640(param_1)` — boolean state queries (guess: runner on 2nd / runner on 3rd).
- Global state `0x68143ee0`:
  - `FUN_68002c80` → byte counter, must be < 2 (guess: outs).
  - `FUN_6800f1e0` → strikes, `FUN_6800f1c0` → balls (guess, from PB names).
  - `FUN_68056985(obj,3,0)` and `(obj,4,0)` → two scores; diff = score(3) − score(4).
- `FUN_6804935e(team_block)` → nonzero = pitcher "wild" (guess).
- All 31 `hnrChance*` PB parameters.

## 3) RULES
1. Gates — all must hold, else chance = 0 (skip to rule 11): `FUN_68032ff0(p) != 0`; `FUN_6800f640(p) == 0`; `FUN_68002c80(global) < 2`; first `IsTracking`-labeled call on `*(p+0x6b)` == 0.
2. `chance = PB[hnrChanceBase]` (25).
3. Score diff `d = score(3) − score(4)` (signed):
   - `d ≤ −3`: `+= PB[hnrChance3MoreBehindAdjust]` (−25)
   - `d == −2`: `+= PB[hnrChance2BehindAdjust]` (0)
   - `d == +1`: `+= PB[hnrChance1AheadAdjust]` (0)
   - `d ≥ +2`: `+= PB[hnrChance2MoreAheadAdjust]` (−10)
   - `d ∈ {−1, 0}`: no adjustment.
4. If `FUN_68032ff0(p) != 0 && FUN_6800f600(p) != 0 && FUN_6800f640(p) == 0` (per PB name: runners on 1st & 2nd only, guess): `+= PB[hnrChanceOn12Adjust]` (−45).
5. SP byte `s` (all band comparisons are strict `thresh < value`; ties fall to lower band):
   - `s ≤ 39`: `+= PB[hnrChanceSlowSPAdjust]` (−10)
   - `40–59`: `+= PB[hnrChanceMedSPAdjust]` (0)
   - `60–79`: `+= PB[hnrChanceFastSPAdjust]` (−5)
   - `s ≥ 80`: `+= PB[hnrChanceVeryFastSPAdjust]` (−20)
6. CH byte `c`:
   - `≤ 39`: `+= PB[hnrChanceLowCHAdjust]` (−40)
   - `40–59`: `+= PB[hnrChanceMedCHAdjust]` (−10)
   - `60–69`: `+= PB[hnrChanceHighCHAdjust]` (+15)
   - `≥ 70`: `+= PB[hnrChanceVeryHighCHAdjust]` (+30)
7. PH byte `h`:
   - `≤ 39`: `+= PB[hnrChanceLowPHAdjust]` (+30)
   - `40–59`: `+= PB[hnrChanceMedPHAdjust]` (+10)
   - `60–79`: `+= PB[hnrChanceHighPHAdjust]` (−30)
   - `≥ 80`: `+= PB[hnrChanceVeryHighPHAdjust]` (−50)
8. If wildness flag (from team block selected by `*(int*)(p+0x7b)==0`) nonzero: `+= PB[hnrChancePitcherWildAdjust]` (−30).
9. Count (balls `b`, strikes `k`), checked in this order:
   - `b == 3`: `+= PB[hnrChance3BallsAdjust]` (+10) — takes precedence; a 3-2 count gets this, not the 2-strike penalty.
   - else `k == 2`: `+= PB[hnrChance2StrikesAdjust]` (−15)
   - else `b == k`: `+= PB[hnrChanceEvenCountAdjust]` (0)
   - else `k == 1 && b == 0`: `+= PB[hnrChance01CountAdjust]` (−15)
   - remaining counts (1-0, 2-0, 2-1): no adjustment.
10. All adjustments are summed into one short.
11. Return `FUN_68014c70(chance, 0, 100)` (clamp to [0,100], guess).

## 4) OUTPUT / SIDE EFFECTS
- Returns uint in [0,100] (presumably a percent chance rolled by the caller, guess). Returns 0 whenever any gate in rule 1 fails.
- No writes to game state visible in the decompile; read-only computation.

## 5) UNCERTAIN

- Semantics of `FUN_68032ff0` / `FUN_6800f600` / `FUN_6800f640` (runner-on-base guesses) and whose SP/CH/PH ratings these are (batter contact/power vs. runner speed / catcher arm / pitcher hold).
- `FUN_68002c80` counter (outs? runners?).
- The three `CSplitterWnd::IsTracking`-labeled calls on `*(p+0x6b)`: if they truly are the same call, the gate (==0) would force CH = PH = 0, making rules 6–7 constant (low bands); assumed mislabeled getters.
- Which team is score index 3 vs. 4 (sign of "behind/ahead").
- `FUN_68014c70` assumed to be clamp(value, lo, hi); whether the result is a percent or a direct roll threshold.
- Layout/meaning of the two team blocks at `0x68114ba8` / `+0x173be` and `FUN_6804935e` (assumed "pitcher is wild" flag).
