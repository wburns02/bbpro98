# FUN_6805c22c () params=1

DRAFT (GLM-Flash, unaudited)

## 1) PURPOSE
Checks whether a derived point for entity `param_1` lies within `PB[tagSyncDist] * 30` units of a reference point built from `this`; if so, records `param_1` in `this+8` and commits a smoothed offset to `this+0x16`, returning the check result.

## 2) INPUTS
- `this` (fields used):
  - `+0x08`: sub-object; a byte is read from it (`FUN_680063c0`) and it is written to on success (`FUN_68002d10`) — *guess: currently attached/tagged entity state*.
  - `+0x0c`: embedded point/frame object used as reference in `FUN_68002bf0` and `FUN_68005d40` — *guess: world position/orientation*.
  - `+0x16`: `short`, persistent accumulator; read and conditionally rewritten — *guess: previous smoothed offset*.
- `param_1`: ID/index; used to look up a record via `FUN_6805b5ea(&DAT_68178510, param_1)` — *guess: player/entity ID*.
- `param_2`: pointer to a record; `param_2+8` is the base passed to `FUN_680039b7` — *guess: animation/sprite record*.

## 3) RULES
1. Look up record `R = FUN_6805b5ea(DAT_68178510, param_1)`; read value `N = (short)FUN_6805b14d(R)`.
2. Fetch pointer `local_c = FUN_680039b7(param_2+8, N*3)` — element at offset/index `N*3` into `param_2+8` data (*guess: per-entity slot*).
3. Read flag byte `F = FUN_680063c0(this+8)`; fetch 6-byte point `P` (three `short`s) via `FUN_6805b35e(R, 0, F)`.
4. `A = (short)FUN_68002bf0(this+0xc, local_c)`; `B = (short)FUN_6801b370(P)`; delta `D = A - B`.
5. `S = FUN_6807c1c0(*(short*)(this+0x16), D, 0x1555)` — combines previous accumulator with `D` using constant `0x1555` (5461 ≈ 65536/12); exact semantics of the helper unknown.
6. Apply `S` to point: `FUN_6807c286(P, S)`; then `FUN_68005d40(P, this+0xc)` (*guess: transform/offset by reference frame*).
7. `dist = FUN_68002bb0(P, local_c)` (unsigned; *guess: distance metric*).
8. Threshold = `PB[tagSyncDist] * 0x1e` (×30). Default `PB[tagSyncDist]=4` → threshold 120.
9. If `dist <= threshold`:
   - `FUN_68002d10(this+8, param_1)` — store/link `param_1` into `this+8`;
   - `*(short*)(this+0x16) = S` — commit smoothed value.
10. Return `dist <= threshold` (the same condition; no commit ⇒ returns false).

## 4) OUTPUT / SIDE EFFECTS
- Returns `bool`: true iff `dist <= PB[tagSyncDist]*30`.
- Side effects (only when true): `this+8` updated via `FUN_68002d10(..., param_1)`; `this+0x16` set to `S`. No other writes to `this` or callers' data observed.
