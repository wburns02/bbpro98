# FUN_68052bd5 () params=49

DRAFT (GLM-Flash, unaudited)

## PURPOSE
Computes a 0–100 "steal chance" rating for the runner on first base (`param_1==2`) or second base (`param_1==3`): a ball/strike-count base value plus speed, pitcher-hold, pitcher-state, wildness, catcher, out-count, and score-deficit adjustments, clamped to [0,100].

## INPUTS
- `param_1`: 2 = runner on 1st (uses "OnFirst" params), 3 = runner on 2nd (uses "OnSecond" params). Any other value → returns 0.
- `this+0x89 + 4*param_1`: pointer to the runner (guess); speed rating read via `FUN_68038e10`.
- `this+0x6b`: pointer to an object whose rating is used as "CH" (guess: catcher).
- `this+0x7b`: int (guess: team index); used in the entry gate lookup and to select one of two records for the wild-pitcher check.
- Global `0x68143ee0` (game state, guess): strikes (`FUN_6800f1e0`), balls (`FUN_6800f1c0`), outs (`FUN_68002c80`), two scores (`FUN_68056985(gs,3,0)`, `FUN_68056985(gs,4,0)`).
- Global `DAT_680a224c` (guess: current-pitcher context): hold rating (low byte of an accessor Ghidra labeled `CSplitterWnd::IsTracking`) and a flag via `FUN_6800f680`.

## RULES
1. **Gate:** if `FUN_6800f270(&DAT_68114948, this+0x7b, 0x40) == 0` → return 0 (guess: per-team state/validity check).
2. **Gate:** proceed only if
   - `param_1==2`: `FUN_68032ff0(this) != 0` AND `FUN_6800f600(this) == 0` (guess: runner on 1st present, 2nd base empty);
   - `param_1==3`: `FUN_6800f600(this) != 0` AND `FUN_6800f640(this) == 0` (guess: runner on 2nd present, 3rd base empty).
   Otherwise return 0.
3. **Base value:** 12 PB bytes are copied to a local table in order `stealChance00Count…stealChance32Count`; base = `table[strikes + balls*3]` (no bounds check). Index mapping implies the PB names are balls–strikes (e.g. `stealChance20Count` = 2 balls 0 strikes = 20) and `FUN_6800f1e0` = strikes, `FUN_6800f1c0` = balls (inferred).
4. **Speed adjust** (`SPD = FUN_68038e10(runner)`), cascade of strict `thresh < SPD` tests:
   - `SPD ≤ PB[stealChanceVerySlowThresh]` (29): `+= PB[stealChanceVerySlowAdjust]` (−80)
   - `SPD ≤ PB[stealChanceSlowThresh]` (39): `+= PB[stealChanceSlowAdjust]` (−40)
   - `SPD ≤ PB[stealChanceMedThresh]` (59): `+= PB[stealChanceMedAdjust]` (−5)
   - `SPD ≤ PB[stealChanceFastThresh]` (79): `+= PB[stealChanceFastAdjust]` (+15)
   - else: `+= PB[stealChanceVeryFastAdjust]` (+20)
5. **Hold adjust** (`HOLD` = low byte of accessor(`DAT_680a224c`)), same cascade:
   - `HOLD ≤ PB[stealChanceVeryLowHoldThresh]` (19): `+= PB[stealChanceVeryLowHoldAdjust]` (+30)
   - `≤ PB[stealChanceLowHoldThresh]` (39): `+= PB[stealChanceLowHoldAdjust]` (+15)
   - `≤ PB[stealChanceMedHoldThresh]` (59): `+= PB[stealChanceMedHoldAdjust]` (+5)
   - `≤ PB[stealChanceHighHoldThresh]` (79): `+= PB[stealChanceHighHoldAdjust]` (−20)
   - else: `+= PB[stealChanceVeryHighHoldAdjust]` (−40)
6. If `FUN_6800f680(DAT_680a224c) == 0`: `+= (param_1==2 ? PB[stealChancePitcherBackAdjust]` (0) `: PB[stealChancePitcherFaceAdjust]` (−5)).
7. If a second call to the same hold accessor(`DAT_680a224c`) returns 0: `+= PB[stealChancePitcherWindupAdjust]` (+5).
8. If low byte of `FUN_6804935e(&DAT_68114ba8 + (this+0x7b==0 ? 0 : 0x173be)) != 0`: `+= PB[stealChancePitcherWildAdjust]` (0).
9. **Runner on 1st** (`param_1==2`), `CH` = accessor(`*(this+0x6b)`):
   - If outs == 2: if `CH ≥ PB[stealChanceOnFirst2OutHighCHThresh]` (59): `+= PB[stealChanceOnFirst2OutHighCHAdjust]` (+10); if `CH ≤ PB[stealChanceOnFirst2OutLowCHThresh]` (39): `+= PB[stealChanceOnFirst2OutLowCHAdjust]` (−10).
   - Else (outs 0 or 1): if `CH ≥ PB[stealChanceOnFirst01OutHighCHThresh]` (59): `+= PB[stealChanceOnFirst01OutHighCHAdjust]` (−5); if `CH ≤ PB[stealChanceOnFirst01OutLowCHThresh]` (39): `+= PB[stealChanceOnFirst01OutLowCHAdjust]` (+5).
10. **Runner on 2nd** (`param_1==3`):
    - outs == 0: `+= PB[stealChanceOnSecond0OutAdjust]` (−15); outs == 1: `+= PB[stealChanceOnSecond1OutAdjust]` (−10); outs == 2: `+= PB[stealChanceOnSecond2OutAdjust]` (−50).
    - If `CH ≥ PB[stealChanceOnSecondHighCHThresh]` (59): `+= PB[stealChanceOnSecondHighCHAdjust]` (−5).
11. **Score:** if `(short)(score3 − score4) ≤ PB[stealChanceWayBehindThresh]` (−3): `+= PB[stealChanceWayBehindAdjust]` (−50). Applied for both param_1 values.
12. All steps are plain 16-bit signed adds into one accumulator (no intermediate clamping); result clamped via `FUN_68014c70(total, 0, 100)` (guess: clamp).

## OUTPUT / SIDE EFFECTS
- Returns uint in [0,100]. On any failed gate returns 0 (accumulator low half is zeroed before the clamp).
- No writes to game state visible; PB table is re-read on every call (live-tunable).
