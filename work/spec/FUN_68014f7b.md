- Return value: low byte 1 on all early-outs and on a successful catch roll; low byte 0 on both miss paths. Mid-miss path returns `(high byte of base) << 8` — likely a decompiler artifact, effectively 0 for base < 256. Final path returns an entity pointer with `& 0xffffff00`.

- Effective chance > 100 ⇒ guaranteed catch (roll caps at 99); ≤ 0 ⇒ guaranteed miss.
