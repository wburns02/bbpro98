**1) PURPOSE**
Loads one 192-byte player record from a roster file by ID into the player object and populates/derives its rating tables (batter, pitcher, fielding, status).

**2) INPUTS**
- `this`: container; sub-objects at `this+4` (player record), `this+0x6b0` (ratings, ≥0x31 int slots), `this+0x29e` (status/injury?, guess), `this+0x774` (derived ratings).
- `param_1`: player ID; must be > 99.
- `param_2`: roster selector; 0 vs nonzero picks one of two adjacent strings at `0x68096f50`/`+8` for the error text (guess: major/minor); passed to `FUN_6803d692`.
- `param_3`: roster file path. File = 2 header bytes + fixed 192-byte records; record for ID n sought at `(n−99)×0xC0` (seek whence unverified).
- Record fields (Ghidra locals; byte offsets not verified): `local_11c` (s16 ID), `auStack_11a[9]` (u16×9), `local_108` (u32, low word used), `local_fe`/`local_ed` (char[17] first/last name), `local_dc`, `local_db` (bats), `local_da` (throws), `local_d9`, `local_d8`, `local_d7`, `local_bf`,`local_be` (CH, PH — guess), `local_bd`,`local_bc`, `local_bb..local_b2`, `abStack_b1[9]` (fielding ratings), `local_a8`,`local_a7`, `local_a5`,`local_a4`, `local_a3..local_a0`, `local_9f[18]` (pitch ratings; `[0x10]` is a signed modifier), `local_8d` (s16), `local_8b`, `local_8a`, `local_86`.
