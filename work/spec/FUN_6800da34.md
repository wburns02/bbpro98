## 1) PURPOSE
Computes a swing-timing value for a fast-sim at-bat by bucketing a weighted timing score (or using a fixed bunt bucket) and drawing the timing from that bucket's parameters.

## 2) INPUTS
`param_1` = pointer to at-bat/batter context struct:
- `+0xf1` (int): rating passed to FUN_68005b80 (guess: batter timing rating).
- `+0xf5` (int): value subtracted from the timing score (guess: penalty, e.g. fatigue/injury).
- `+0xf9` (char): flag; subtraction applies only when it is 0 (guess: "penalty exempt" flag).
- `+0xbd` (int): compared to 3; selects bunt parameter set (guess: swing/action type, 3 = bunt).

PB parameters: all those listed (idRatingTimingWeight, timingVeryBad*/Bad*/Med*/Good*/VeryGood*/Bunt*).

2. If `ctx[0xf9] == 0`: `score -= ctx[0xf5]`.
3. Select `(count, faces, base)`:

   - Else if `score < PB[timingBadThresh]` (65): bad = (2, 40, -41).
