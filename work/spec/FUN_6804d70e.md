1. Return **FALSE** iff ALL of the following hold (negation of the outer gate):
   - `FUN_680099c0(0x6809f510) != 0`, AND
   - `FUN_68009700(0x6809f515)` is false, AND

   - `FUN_68003090(0x680d26b0) != 0`, AND
   - `FUN_68002c80(0x68143ee0) != 2`, AND
   - `FUN_6801f580(param_1)` is false.
2. Return **TRUE** iff `FUN_680099c0(0x6809f510) != 0` AND `FUN_68003090(0x680d26b0) != 0` AND `FUN_68002c80(0x68143ee0) == 2`. (Reachable only when rule 1's gate was passed via `FUN_68009700` true, the `0x6809f515` byte flag nonzero, or `FUN_6801f580` true.)
