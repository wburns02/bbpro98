## 6803a6f0 — Wind vector builder (cached)

**PURPOSE**
Builds (or returns the cached) wind vector used for ball flight, from the current wind direction/speed state, with speed scaled by `PB[ballWindSpeedPct]`.

**INPUTS**
- Wind state struct at `0x68114948`:
  - byte read via `FUN_6803bdf0` → wind direction index (assumed 0–7; used to index an 8-entry table) *(guess: compass octant)*
  - value read via `FUN_6803bdd0`, used as `short` → raw wind speed
- `FUN_6803a5ff()` result → third wind scalar, meaning unknown *(guess: vertical/gust component)*
- `PB[ballWindSpeedPct]` (default 40)
- Statics: cache slots `DAT_68096a5c` (dir), `DAT_68096a60` (scaled speed), `DAT_68096a64` (third scalar); result object `DAT_68114890`; init-flag word `DAT_68114870`

**RULES**
1. One-time init (bit 0 of `DAT_68114870`): set flag, init `DAT_68114890` to (0,0,0) via `FUN_68011090`, register atexit dtor `FUN_6803a8d9`.
2. Read current direction, raw speed, and `FUN_6803a5ff()` value. If all three equal the cached `DAT_68096a5c` / `DAT_68096a60` / `DAT_68096a64`, return `&DAT_68114890` unchanged (cache hit).
3. On cache miss: store direction; store `FUN_68005b80(rawSpeed, PB[ballWindSpeedPct])` as scaled speed *(assumed percent math: rawSpeed × pct / 100)*; store `FUN_6803a5ff()` result.
4. One-time table init (bit 1): build 8 direction vectors, 12-byte stride (3 ints, z=0), directions scaled to magnitude ~10:
   - idx 0: (0, −10) · idx 1: (7, −7) · idx 2: (10, 0) · idx 3: (7, 7)
   - idx 4: (0, 10) · idx 5: (−7, 7) · idx 6: (−10, 0) · idx 7: (−7, −7)
   Register atexit dtor `FUN_6803a8c9`.
5. Copy table entry `[direction]` into `DAT_68114890` (`FUN_68014b50`).
6. Apply scaled speed shifted left 6 (`speed << 6`, i.e. ×64; assumed fixed-point) via `FUN_6803bce0`.
7. Apply cached third scalar via `FUN_6803bd30`, then apply constant `10` via a second `FUN_6803bd30` call.
8. Return `&DAT_68114890`.

**OUTPUT / SIDE EFFECTS**

- Side effects: updates the three cache slots; sets init-flag bits; registers two atexit destructors on first use.
