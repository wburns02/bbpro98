# FUN_680447dc () params=5

DRAFT (GLM-Flash, unaudited)

## PURPOSE
Per-game-second updater that accrues or decays a condition value (field 4) for each of 40 pitcher records based on elapsed time and the pitcher's activity state (resting / warming up / in-game), at PB-configured seconds-per-pitch intervals.

## INPUTS
- `param_1`: staff/team object; array of 40 records, stride 0x93c, first record at offset 0x3de.
- Per record, via getter `FUN_6803e1b2(rec, N)` (N = field index):
  - field 3: int — cap for field 4 (guess)
  - field 4: int — condition accumulator, clamped to [0, field3] (guess: fatigue)
  - field 5: int — timestamp anchoring start of cool-down (guess)
  - field 6: uint — last-processed game time
  - field 8: int — counter incremented in tandem with field 4 when throwing (guess: throw count)
  - field 10: int — over-cap overflow accumulator (guess)
- `FUN_6803dded(rec)` → state 0–4; `FUN_6803df0d(rec)` → sub-state int (tested `< 2`).
- Global clock object `0x68143ee0`: `FUN_6804ad60` → current time T (16-bit); `FUN_680076c0` → value compared to `*(int*)(param_1+0x17330)`.
- Global `0x681147a0`: `FUN_68039407` → boolean gate for quick-pitch rate.
- `*(int*)(param_1+0x172c4)`: index compared against loop index (guess: active/current pitcher).
- PB params, each passed through `FUN_68002dd0(v, 1)` (assumed max(v,1)): warmupSecsPerWarmPitch (30), warmupSecsPerQuickPitch (15), warmupSecsPerMaintPitch (120), warmupSecsPerCoolPitch (60), warmupSecsBeforeCool (1200).

## RULES
1. T = `FUN_6804ad60(0x68143ee0)` (16-bit game time). Rates: WARM = max(PB[warmupSecsPerWarmPitch],1); QUICK = max(PB[warmupSecsPerQuickPitch],1); MAINT = max(PB[warmupSecsPerMaintPitch],1); COOL = max(PB[warmupSecsPerCoolPitch],1); DELAY = max(PB[warmupSecsBeforeCool],1).
2. For i = 0..39, rec = `param_1 + i*0x93c + 0x3de`:
3. Skip record if field6 == T (already processed this second). Otherwise elapsed = (uint)(T − field6).
4. Switch on state:
   - **State 0 or 1 (resting):** coolStart = field5 + DELAY. If coolStart < T: eff = (field6 < coolStart) ? T − coolStart : elapsed; field4 −= eff / COOL; field6 += (eff / COOL) * COOL. (Condition decays 1 per COOL seconds, beginning DELAY seconds after field5; only whole COOL-second intervals consumed — remainder stays in field6.)
   - **State 2 (warming up):** if substate < 2: rate = QUICK if (`FUN_680076c0(clock)` == `*(int*)(param_1+0x17330)` AND `FUN_68039407(0x681147a0)` returns nonzero/non-negative), else rate = WARM; else rate = MAINT. n = elapsed / rate; field4 += n; field8 += n; if field3 <= field4: field10 += field4 − field3; field6 += n * rate.
   - **State 3 or 4:** if `*(int*)(param_1+0x172c4)` != i AND substate < 2: n = elapsed / WARM; field4 += n; field8 += n; field6 += n * WARM. (No overflow-to-field10 branch here; if the guard fails, nothing is updated and field6 is not advanced.)
5. After the switch: field4 = `FUN_6800f0e0`(field4, 0, field3) — clamp to [0, field3] (field4 may go negative in state 0/1 before this clamp).
6. `FUN_68049d61(param_1, i)` is called for every non-skipped record, even if no branch modified anything.

## OUTPUT / SIDE EFFECTS
- Returns nothing. Mutates per-record fields 4, 6, 8, 10. Calls `FUN_68049d61` per updated record (side effects unknown).

## UNCERTAIN
- Semantics of all fields and states (fatigue vs. readiness; meaning of states 0–4 and of substate threshold 2) — inferred from arithmetic only.
- `FUN_68002dd0` assumed max(v,1); `FUN_6800f0e0` assumed clamp(v, lo, hi); purpose of `FUN_68049d61` unknown.
- Meaning of `*(int*)(param_1+0x17330)` and of the two global queries (`FUN_680076c0`, `FUN_68039407`) that enable the QUICK rate.
- Meaning of `*(int*)(param_1+0x172c4)` (why that record is excluded in states 3/4 — possibly handled elsewhere, e.g., active pitcher).
- Time unit assumed to be seconds (per PB names); T is 16-bit and wraps at 65536; elapsed uses unsigned wraparound subtraction.
- In states 3/4 with a failed guard, field6 is not advanced, so elapsed accumulates until the guard passes (catch-up burst) — behavior as coded, intent unknown.
