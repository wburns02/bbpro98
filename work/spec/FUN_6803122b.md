# FUN_6803122b (void __fastcall FUN_6803122b(int param_1))

**PURPOSE**
Resolves the pitcher's selected pitch into actual attributes — final location, velocity, movement, and possibly a changed pitch type — via fatigue penalties and control/movement rolls, then starts the pitch animation.

**INPUTS** (param_1 = pitch context object; offsets hex)
- +0xe7 int: selected pitch type 0–7 (9 gets special pre-handling) [inferred]
- +0xf5 int: pitch power/effort selector; values 0, 2, 4 acted on [inferred]
- +0xeb short / +0xed short: horizontal / vertical aim point (signed)
- +0x7d int: mirror flag; when 1, movement and release x are negated [guess: handedness]
- +0x8b int: selects release-point variant (0 vs nonzero)
- +0x85: bit 0x200 tested (UI condition)
- +0xdf ptr: object passed to final call
- Via +0x70 (pitcher struct): +0x774 ratings table — FUN_6803e377(t, pitchType) = pitch rating; FUN_6803e39f(t, 1/2/3) = attributes "AS", "CO", "MO" (names inferred from PB params; layout unknown); +0x29e fatigue state via FUN_6803df0d, 3 = tired, 4 = exhausted [inferred from PB names]

Shorthand: PCT(a,b) = FUN_68005b80, assumed a·b/100; RND(n) = FUN_68082999, assumed uniform 0..n−1; FUN_68082a2d(rng,n) assumed true with probability n%; FUN_68009560 assumed |x|; FUN_68005cc0(x,99) assumed clamp to 99; FUN_6800f220(x,pct) assumed in-place scale.

3. Fatigue: state 3 → rating = PCT(rating, PB[tiredPitchRatPct]), AS = PCT(AS, PB[tiredASPct]); state 4 → rating = PCT(rating, PB[exhaustedPitchRatPct]), AS = PCT(AS, PB[exhaustedASPct]).
4. effCO = PCT(PCT(CO, rating), PB[effCOPct]); missCO = RND(100) − effCO; controlOK ⇔ missCO < 1.
5. effMO = PCT(PCT(MO, rating), PB[effMOPct]); missMO = RND(100) − effMO (independent roll); moveOK ⇔ missMO < 1; +0x10d = moveOK ? 0 : 1.
6. speed (+0x105) = FUN_6802edfd(pitchType, AS); power==2 → speed += 5; power==0 → speed −= 5.

8. scatterX = RND(breakX); scatterY = RND(breakY).
9. Location: if aimX < 0 → aimX = aimX − breakX/2 + scatterX; else aimX = aimX + breakX/2 − scatterX. aimY = aimY + breakY/2 − scatterY. +0x101 = (|scatterX| < 6 && |scatterY| < 6) ? 1 : 3.

    - 6: r = RND(100); AS < 50 → outcome 1 if r < 50 else 2; AS ≥ 50 → 0 if r < 33 (0x21), 1 if r < 66 (0x42), else 2.

    - Outcome 2: effMO −= missMO.
12. aux = PCT(effMO, 11) + 5 (5th arg to final call).
13. +0xef/+0xf3 ← FUN_68005ba0(0,0,0); +0xf3 ← 0x8000. Then low short of +0xef by (possibly changed) pitchType: 0,5,7 → 0xfc72 (−910); 1,2,4 → 0xf556 (−2730); 3 → 0xfb06 (−1258); 6 → 0xf8e4 (−1820). Type 9 has no case (default kept).

15. Release point: +0x8b==0 → (−45, 1800, 200); else (−110, 1800, 80); if +0x7d==1, x ← −x.
