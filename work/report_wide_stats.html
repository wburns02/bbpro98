Verdict

Mostly done, not 100%. The in-game League Statistics screen now shows 12 columns at once and is installed in the live game. Batting adds OBP, SLG, Pro and Iso. Pitching adds ER, HR, K/9 and BB/9. This replaces the earlier "not 100%" verdict, when the in-game widening had failed. Lineup, Hall of Fame and a full season were not tested.

What was accomplished

  • Root cause found: the screen is built from SHELL.VOL (DIAL.REQ block 13), not from the BBShell code the earlier patches targeted. Blocks that start above roughly 0xfe9x fail to load, so a large block was moved to the end of the volume (wide5).
  • Seven in-memory hooks in bbfix.dll (src-latest/bbfix.c) add four body and four header gadgets and map them to stat ids. All-or-nothing, original bytes verified first, on-disk BBShell.dll stays pristine, re-applied on every load. Stat ids come from bbfix.ini.
  • Installed in the live game with work/patches/install_live.sh. Revert with revert_live.sh, which restores the pristine 2006-end backup.
  • Found the grid's real text routine (DrawText_Shell 68065650) and added a flag-gated trace hook. This is the base for the Career-data click-through idea.
  • Ghidra 12.1.4 is now the live source of truth: 14 binaries in /mnt/nvme/bbpro98/ghidra_proj, queried and edited through gh.sh (pyghidra-mcp on port 18765). Named stats, STS, window-create, grid and text functions. Defined the StatSet struct. Regenerated _all.c.
  • Process: work copy at /mnt/nvme/bbpro98/work_install with scripts that refuse the live target; private git repo (three more commits, not pushed); HANDOFF.md, progress.md and the memory file updated.

Landmines learned

  • The thiscall helpers 680436c0 and 68043400 take two stack args and ret 8. Calling them with the wrong cleanup corrupts the stack.
  • Hooks must be re-applied each time BBShell loads; it is unmapped and remapped per screen. Verify bytes, hook all sites or none.
  • Game text is not GDI. GDI trace hooks log nothing for grid text.
  • The "DLL loaded" path check must compare 9 characters, not 10 (the NUL broke it).
  • Ghidra project lock: stop the MCP server before batch edits; gh.sh batch does this.
  • Test sims need 1997 opening-day data; the 2006-end state sits at season-complete and Simulate is greyed.
