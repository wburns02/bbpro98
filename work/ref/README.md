# Community tools and tuning sets (third party)

Freeware from the Baseball Pro '98 community, kept here as reference oracles for the file formats and PlayBalance work. No license or redistribution terms were included with any of these. All credit goes to the original authors. If you are one of them and want something removed, open an issue.

| Path | What | Author |
|------|------|--------|
| `bbcard/` | BBCARD, player card / association report utility (DOS) | kammrud (kammrud@juno.com, www.vol.com/~kammrud) |
| `bbrecord/` | BBRECORD season records utility, plus HTMLIZE | kammrud |
| `pb51/5.1pb.ini`, `pb6/pb6.ini` | PlayBalance tuning sets v5.1 and v6.0 | "Knuckleball Lover" |
| `pbini/PB.INI` | PlayBalance tuning set (defensive positioning) | unknown |
